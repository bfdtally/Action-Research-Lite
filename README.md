# FAMU COE Action Research Learning Lab

An undergraduate instructional simulation for learning the action research cycle through fictional classroom cases and synthetic data.

## Product boundary

This application is a practice environment, not a research-production system. It intentionally:

- uses only fictional cases and synthetic evidence;
- accepts no uploads or identifiable participant data;
- redirects real, graduate, thesis, dissertation, IRB, and publication work;
- requires students to make decisions before revealing coaching;
- produces a watermarked learning report rather than a submission-ready paper; and
- stores progress only in the current browser.

The full Action Research Navigator remains a separate application outside this folder.

## Local development

```sh
pnpm install
pnpm dev
```

Use `pnpm build` and `pnpm lint` to validate the application. Do not deploy or publish this project without explicit approval.
